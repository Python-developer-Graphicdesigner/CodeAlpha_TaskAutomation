# CodeAlpha - Task Automation: Email Address Extractor (Python)

## Internship Task
This project was built as part of the CodeAlpha Python Programming Internship — Task 3: Task Automation with Python Scripts.

## Description
A Python script that automates a small, repetitive real-life task: scanning a .txt file, extracting every email address found inside it using a regular expression, removing duplicates, and saving the clean list of unique email addresses into a new output file.

## Features
- Scans any .txt file provided by the user
- Uses a regular expression to accurately detect email address patterns
- Removes duplicate email addresses automatically
- Sorts the results alphabetically
- Saves the extracted emails to a new output file
- Handles missing files and empty results gracefully

## Key Concepts Used
- os module (file path handling)
- re module (regular expressions)
- File handling (reading and writing files)

## How to Run
1. Make sure Python 3 is installed on your system.
2. Download extract_emails.py and sample_input.txt into the same folder.
3. Open a terminal in that folder.
4. Run the script:
   python 3
